# Petstore API Testing

## Описание проекта

Автоматизированное тестирование Petstore API с использованием Python, pytest, requests и Allure.

## Что проверяется

- Pet - создание, получение, изменение и удаление питомцев.
- Store - работа с заказами и получение инвентаря.
- User - создание, получение, изменение и удаление пользователей.
- Позитивные и негативные сценарии тестирования.

## Запуск тестов

```bash
python -m pytest ./tests -v
```
